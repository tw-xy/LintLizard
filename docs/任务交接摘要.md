## 5. 树莓派侧已做的系统改动

- **UART**：`/boot/firmware/config.txt` 末尾（`[all]` 段）加 `enable_uart=1` + `dtoverlay=disable-bt`；
  `/boot/firmware/cmdline.txt` 去掉 `console=serial0,115200`；重启后 `/dev/serial0 -> ttyAMA0`（PL011，115200 8N1）
- **WiFi 省电**：`nmcli connection modify miaomiaomao2.4G wifi.powersave 2`
- **Web 服务**：`pi/server.py`（纯标准库，无 pip 依赖）+ `pi/lintlizard-web.service`（systemd 开机自启）
  - 部署：`scp pi/server.py pi@<IP>:/home/pi/lintlizard-server.py`
  - 排查：`systemctl status lintlizard-web` / `journalctl -u lintlizard-web -n 50` / `curl -s localhost:8080/status`
  - 接口：`/` 页面、`/cmd?x=&y=` 指令、`/video` MJPEG、`/scan` 点云、`/status` 状态

## 6. 已排除的错误方案 / 必须记住的坑

1. **ESP8266 的 EN 必须接 3.3V**，悬空不启动（蓝灯不亮）
2. **ESP 供电不能从 USB-TTL 或板子 3.3V 取**，要独立 3.3V（≥500mA）
3. **YDLIDAR X2 第 4 脚是 `M_CTR`（电机调速），不是卖家标的 `RXD`**
4. **Raspberry Pi Imager 2.0.11.1 会崩**（`libstdc++-6.dll`），用 **1.9.6**
5. **Clash TUN 会劫持局域网 IPv4**：症状是 IPv4 超时但 IPv6 通、ARP 通 → 关掉 TUN
6. **中文 SSID 在 Linux 控制台打不出来** → 改英文；路由器**实际 2.4G 名是 `miaomiaomao2.4G`**（是 `mao` 不是 `miao`），5G 才是 `miaomiaomiao5G`
7. **树莓派 UART 默认没开**（`/dev/ttyAMA0` 都不存在），按第 5 节那三步改
8. **WiFi 省电会导致树莓派随机掉线**，已关
9. `.ps1` 在 PowerShell 5.1 会中文乱码 → 脚本一律纯 ASCII
10. **Clash fake-IP 会让 `lintlizard.local` 解析到 `198.18.0.x`** → 直接用真实 IP
11. 树莓派**屏蔽 ICMP**，`ping` 不通不代表掉线，要用 SSH/端口判活
12. `git` 里已经把 `*.py/*.service/*.sh` 设为 LF（`.gitattributes`）

## 10. 远期规划与架构要求

- 远期：扫地主刷/滚刷、自动回充（红外寻桩 + 触点）、ToF/超声波、GPS/罗盘、OLED 弹幕、WS2812、ESP32-CAM 图传
- 架构硬要求：**非阻塞**（时间片轮询），**严禁 `Delay_Ms()` 死等**；
  分层 `User/(主循环) Bsp/(时基/串口/电机/风机/OLED) App/(协议/差速/扫地/雷达/避障/巡航/UI)`，参数集中在 `App/app_config.h`
- 失效保护三层：ESP/Pi 端超时回中 → 链路 300ms 判离线 → 底盘输出归零；雷达失效锁前进
