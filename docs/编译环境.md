## 3. 从零恢复（换电脑 / 重装系统后）

1. 装 MounRiver Studio 2（自带工具链和 OpenOCD）
2. 装 Arduino IDE 2.3.10
3. 加开发板管理器网址 `https://arduino.esp8266.com/stable/package_esp8266com_index.json`，装 `esp8266 by ESP8266 Community`
4. 库管理器装 `Blinker`（作者 i3water）
5. clone 本仓库 → 直接 `build.ps1` 就能编译（**SDK 已随仓库自带**，不需要额外下 EVT 包）

## 4. 网络/代理（国内环境必看）

**Arduino CLI 不读系统代理、也不读 `HTTP_PROXY` 环境变量**，所以装开发板包/库会一直超时。
解决办法是写它自己的配置文件 `%LOCALAPPDATA%\Arduino15\arduino-cli.yaml`：

```yaml
network:
  proxy: http://127.0.0.1:7897    # 改成你自己的代理端口（ClashVerge 默认 7897）
```

不需要时删掉该文件即可。**这一条只影响下载，不影响本地编译。**

## 5. 编译 / 烧录 / 记录

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1              # 编译
powershell -ExecutionPolicy Bypass -File .\flash.ps1              # 烧录（覆盖板子现有程序）
powershell -ExecutionPolicy Bypass -File .\log.ps1 -Seconds 60    # 录 COM4 到 logs\
```

`build.ps1` 的 SDK 查找顺序（本目录下）：

1. 环境变量 `CH32V307_SDK`（可指向 `...\EXAM` 或 `...\EXAM\SRC`）
2. **仓库自带 `sdk\`**（默认走这条）
3. `sdk_path.txt`（本地文件，已被 git 忽略）
4. 内置默认路径 `D:\WCH_CH32V307_EVT\extracted\EVT\EXAM`

编译选项与 MounRiver 官方 `obj` 配置一致：
`-march=rv32i -mabi=ilp32 -Os -std=gnu99 --specs=nano.specs --specs=nosys.specs -nostartfiles -Wl,--gc-sections`

当前占用：**FLASH 12220 B / 288 KB（4.14%）**，**RAM 3400 B / 32 KB（10.38%）**。

## 6. ESP8266 端编译设置

| 项 | 值 |
|---|---|
| Board | Generic ESP8266 Module |
| Flash Size | **1MB (FS:none OTA:~502KB)** |
| Crystal | 26 MHz |
| CPU | 80 MHz |
| Upload Speed | 115200 |
| 端口 | **USB-TTL 的 COM 口**（不是 COM4） |

当前占用：Flash 504672 B（48%）、RAM 35952 B（44%）、IRAM 92%。

命令行编译（不用开 IDE）：

```powershell
& 'D:\Arduino IDE 2.3.10\resources\app\lib\backend\resources\arduino-cli.exe' compile `
  --fqbn esp8266:esp8266:generic --board-options "eesz=1M" `
  'D:\WCH_CH32V307_EVT\projects\CAR_REMOTE\esp8266\ESP8266_Blinker_Joy'
```
